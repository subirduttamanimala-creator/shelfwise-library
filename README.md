# Morrow City Library

A polished, responsive public-library website concept with a broad starter catalog and a friendly circulation desk. Built with plain HTML, CSS, and JavaScript; no build step is required.

## What’s inside

- 100+ curated titles across computing, electrical, mechanical, civil, engineering core subjects, GATE and study, fiction, classics, and science
- Recent and noteworthy books, reader favourites, and engineering study shelves
- Catalog search across title, author, subject, topic tags, edition, and year
- Category, availability, recency, and popularity filters with sorting
- Mira, a local catalog-powered book finder that matches a reader’s mood or subject to titles already on the shelves
- A circulation desk that records the reader, member card, checkout date, due date, loan duration, returns, and renewals
- Reader profile, saved reading list, and example membership tiers
- A greeting that changes by local time: morning from 6:00 to 11:59, afternoon from 12:00 to 16:59, evening from 17:00 to 20:59, and night otherwise
- Responsive desktop and mobile layouts

## Run locally

Open `index.html` in a current browser. The sample collection appears on first use. Bookmarks, reader profile, selected plan, and circulation changes are stored in the browser’s local storage under `morrow-library-v1`.

## Publish with GitHub Pages

1. Push the project files to the repository’s `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
3. GitHub Pages publishes the site and updates it when `main` changes.

## Demo limitations

This is a front-end project preview. Reader records are stored separately in each browser and are not shared with other devices or library staff. Mira uses local catalog matching and is not connected to a generative AI service. Membership prices are sample tiers; the site does not collect payments. A real operating library would need secure staff/member authentication, a shared database and API, privacy controls, and a payment provider before handling live accounts or fees.
